# 주문의 갈림길

자동으로 회랑을 돌파하는 마법학교 실습생이 되어, 적의 대형을 읽고 숫자 주문으로 대응하는 실시간 전투 게임입니다.

## 실행

저장소를 내려받아 [주문의 갈림길](outputs/주문의%20갈림길.html)을 브라우저로 여세요. 설치 없이 숫자 키나 입력판 클릭으로 플레이할 수 있습니다. 숙련도와 승급 기록은 플레이한 브라우저에 저장됩니다.

| 주문 | 입력 |
| --- | --- |
| 빛방패 | ③④ |
| 별사슬 속박 | ③① |
| 돌창 | ②① |
| 성월파 | ⑤⑥⑨ · 3서클 승급 후 |

포대 회랑과 관측 회랑에서 각각 문지기를 쓰러뜨리면 승급 시험이 열립니다. 승급 후 첫 매복에서는 세 핵이 한 줄에 모이는 순간을 노려 보세요.
